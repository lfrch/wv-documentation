# wv-documentation

Dieses Repository ist eine Docusaurus-Site zur Dokumentation eines empirischen Projekts.

## Lokal starten

1. Abhängigkeiten mit `npm install` installieren.
2. Die Website mit `npm start` starten.
3. Die lokale Browser-Vorschau öffnen und die Indexseite zur Navigation verwenden.

## GitHub Pages

- Die Seite wird per GitHub Actions Workflow unter `.github/workflows/deploy-pages.yml` gebaut und veröffentlicht.
- Ziel-URL: `https://lfrch.github.io/wv-documentation/`
- Für die erste Veröffentlichung in GitHub unter **Settings → Pages** als Source **GitHub Actions** auswählen.

## Seitenstruktur

- [Index](content/index.md)
- [Methode](content/method.md)
- [Literaturanalyse](content/literature-analysis.md)
- [Artefakte](content/artifacts.md)
- [Ergebnisse](content/findings.md)

## Empfohlene Reihenfolge

1. Mit der Indexseite für Überblick und Navigation beginnen.
2. Die Methodenseite nutzen, um die Durchführung der empirischen Arbeit nachzuvollziehen.
3. Die Literaturanalyse lesen, um die Forschungslage einzuordnen.
4. Zur Ergebnisse-Seite wechseln, um Resultate und Beobachtungen zu sehen.
5. Begleitmaterial auf der Artefakte-Seite sammeln.
